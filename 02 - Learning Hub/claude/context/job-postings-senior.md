## Batch 1 (COMPLETO — 12/12) — UK + remote focus

### #1 — Generico Backend Engineer (Part-time, Remote, $70-150/h)

**Meta:** Contractor IC, $70-150/h (~$140-300k equiv), remote, project-based
**Stack:** API + microservices + database optimization + distributed systems
**Soft skills:** Strong communication, indipendenza, flessibilità project-based
**Insight:** Annuncio brevissimo/generico → **baseline minimo contractor remote**. Nessun framework specifico, conta solo "saper fare". Range salariale conferma che remote contractor senior backend in USD = top-tier income.

### Stack frequency dopo 12 annunci

**Linguaggi backend (frequenza):**
- **Node.js/TypeScript**: 7/12 (Nothing, Trainline, Accenture, Freetrade, Elliptic, recruiter £50-60k, Paloma) → **lingua franca emergente UK 2026**
- **Java**: 4/12 (Spotify, NatWest, Accenture, Deutsche Bank) → **standard fintech enterprise UK**
- **C#/.NET**: 4/12 (TP ICAP, Trainline, Paloma, generic) → **forte in fintech specifici e travel/booking**
- **Python**: 4/12 (Nothing, Accenture, Deutsche Bank, Paloma implicito) → **AI/data engineering**

**Cloud providers:**
- **AWS**: 8/12 → standard de facto
- **GCP**: 3/12 (Freetrade, Paloma, Deutsche Bank BigQuery)
- **Azure**: 1/12 (Accenture menzionato)

**Skill differenzianti emerse:**
- **Containerization (Docker/K8s)**: 6/12 esplicito
- **Messaging (Kafka/RabbitMQ/Solace/SQS/event-driven)**: 7/12
- **Observability esplicita** (New Relic, ELK, Prometheus, Grafana, tracing): 4/12 → in crescita
- **Terraform IaC**: 3/12 (Trainline, Elliptic, Pulumi in Paloma)
- **TDD/BDD esplicito**: 3/12 (TP ICAP, recruiter £50-60k, implicito altri)
- **AI tools coding (Claude Code/Cursor/Windsurf) richiesti per nome**: 1/12 (Paloma) — primo signal "spec-driven dev"!
- **AI/LLM/RAG production**: 3/12 (Nothing, Paloma, Accenture cert obbligatoria)
- **Identity standards (OAuth/SAML/SCIM/Auth0)**: 1/12 (Elliptic)
- **Big Data (Hadoop/Spark/BigQuery)**: 1/12 (Deutsche Bank)
- **Low-latency / multithreading**: 1/12 (TP ICAP)
- **DAPR**: 1/12 (TP ICAP)

**Salary anchors UK emersi:**
- £50-60k: mid junior remote (recruiter)
- £52-75k: mid London fintech (Freetrade)
- £85k: senior healthcare AI (Paloma)
- TP ICAP, Spotify, NatWest, Deutsche Bank: non specificato (presunti £80-130k)

**Trend cross-cluster (importante):**
1. **Stack-agnosticismo cresciuto** dopo 12 annunci: 4 linguaggi mainstream coexistono (Node/Java/C#/Python)
2. **Node.js + TypeScript supera C#** in frequenza per ruoli mid-senior generalisti
3. **AI cert / portfolio diventa prerequisito** in 3+ annunci (Accenture obbligatoria, Paloma nice-to-have, Nothing AI fluency)
4. **AI coding tools richiesti per nome** (Paloma) → conferma trend Cluster #4 AI-Augmented SWE batch AI/FE
5. **Cloud tripletta (AWS/GCP/Azure)** = aspettativa "almeno uno hands-on", AWS dominante
6. **TDD esplicito raro** (3/12) — sorprendente, dato il marketing SE roadmap. Mercato lo dà per scontato, non lo specifica
7. **Observability stack** in crescita (4/12) → trend 2026 verso production-grade ownership
8. **Identity standards (Auth0/OAuth/SAML)** emerge come skill differenziante per Customer Platform / multi-tenant SaaS
9. **Big Data** appare solo in fintech enterprise (Deutsche Bank) — niche ma stabile
