# 🏆 AZ-204 — Azure Developer Associate

> **Status:** not-started · scheduled in **Tier 1 cert pipeline** (Year 1)
>
> **Why this cert:** highest ROI cert per profilo Dan (UK, .NET-focused, target Senior Engineer / AI Engineer). Copre Azure App Service, Functions, Container Apps, AKS basics, Cosmos DB, Service Bus, Key Vault, Blob Storage, **.NET Aspire** (recently added). Quasi ogni job listing UK Senior .NET la richiede o premia.
