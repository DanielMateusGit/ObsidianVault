## 💡 Possibili Progetti

### Opzione 1: AI-Powered Task Manager
- Input: "Voglio un task manager con priorità smart"
- AI: Design domain model
- AI: Implementa entities, value objects, events
- AI: Setup hooks (tsc, lint, test)
- AI: MCP GitHub per repo management
- Hook: Claude SDK review semantico
- Human: Approva PR
- AI: Deploy automatico

**Automazione:** ~85-90%

---

### Opzione 2: Documentation Generator
- Input: Codebase esistente
- AI: Analizza architettura
- AI: Genera C4 diagrams
- AI: Crea ADR per decisioni chiave
- AI: Setup automation docs update
- Hook: Docs sempre sync con code
- Human: Review high-level architecture
- AI: Mantiene docs aggiornate

**Automazione:** ~80-85%

---

### Opzione 3: AI Code Review Bot
- Trigger: PR aperta (GitHub webhook)
- AI: Analizza diff
- Hook: Claude SDK review per:
  - Security issues
  - Performance problems
  - Architecture violations
  - Best practices
- AI: Commenta su PR con findings
- Human: Valuta findings + approva
- AI: Auto-merge se tutti check OK

**Automazione:** ~90%
