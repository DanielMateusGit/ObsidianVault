# 🎓 Sistema Esami

Questa cartella contiene gli esami per verificare le conoscenze acquisite.

## 📋 Come Funziona

1. **Claude propone l'esame** → "Sei pronto per una verifica?"
2. **Viene creato il file** → `esame_YYYY-MM-DD.md`
3. **Dan compila le risposte** direttamente nel file
4. **Dan dice** → "Ho finito l'esame"
5. **Claude corregge** → Voto in trentesimi + feedback

## 📊 Struttura Esame

| Parte | Punti | Tipo |
|-------|-------|------|
| A | 10 | Domande aperte |
| B | 6 | Domande chiuse (multiple choice) |
| C | 8 | Codice (correggere/refactoring/scrivere) |
| D | 6 | Design/Architettura |
| **Tot** | **30** | |

## 🏆 XP per Voto

| Voto | XP | Descrizione |
|------|-----|-------------|
| ≥27/30 | +200 | Superato con lode |
| ≥24/30 | +150 | Superato con merito |
| ≥18/30 | +100 | Superato |
| <18/30 | +30 | Tentativo + piano ripasso |

## 🎯 Quando si Fanno

- **Fine progetto/milestone** → Obbligatorio
- **Weekend/Lunedì** → Su proposta di Claude
- **Su richiesta** → "Voglio ripassare X"
- **Pre-certificazione** → Simulazione esame reale
